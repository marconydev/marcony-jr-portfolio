# Atualizar o repositório existente com a V9

Após testar localmente, copie `index.html`, `main.js` e `hero-transition-v9.css` para a raiz do repositório clonado (`marcony-jr-git`). O `package.json` atualizado é opcional.

```bash
git add index.html main.js hero-transition-v9.css package.json
git commit -m "Manter card fixo e animar somente textos no hero"
git push origin main
```

Não mova a pasta `assets`. O workflow GitHub Pages existente continua servindo a raiz do repositório.
